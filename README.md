🚧 Road Accident Analysis Dashboard (Power BI)

📊 Overview

This project presents an interactive **Power BI dashboard** analyzing road accidents across India.  
It focuses on identifying trends, risk factors, and safety patterns to support data-driven decision-making.


🎯 Objectives

- Analyze accident trends over time  
- Identify high-risk states and road types  
- Understand impact of weather, time, and visibility  
- Evaluate road safety and efficiency  
- Provide actionable insights using advanced visuals

📌 Key Features

- 📊 **Overview Dashboard** – High-level accident insights  
- 🗺 **State-wise Analysis** – Regional comparison  
- 🛣 **Road Type Analysis** – Risk & behavior patterns  
- 📈 **Trend Analysis** – Year-wise accident trends  
- ⚠ **Safety Analysis** – Risk score & accident severity  
- 🧠 **Smart Insights** – AI-driven analysis (Key Influencers & Decomposition Tree)  
- 📖 **Story Dashboard** – Executive summary  


🛠 Tools & Technologies

- Power BI  
- DAX (Data Analysis Expressions)  
- Data Visualization  
- Data Modeling  


📊 Dataset Details

The dataset includes:

- Location (State, City, Coordinates)  
- Time (Year, Month, Hour, Day)  
- Road Type & Conditions  
- Weather & Visibility  
- Accident Severity & Risk Score  
- Casualties & Vehicles Involved  


🚀 How to Use

1. Download the `.pbix` file from `dashboard/`
2. Open in Power BI Desktop
3. Use slicers to filter:
   - State  
   - Year  
   - Road Type  
   - Weather  
   - Time of Day  
4. Explore interactive visuals and insights  


💡 Key Insights

- Highways show higher risk levels  
- Night-time accidents are more severe  
- Weather and visibility significantly impact risk  
- Some states have disproportionately high accident rates
